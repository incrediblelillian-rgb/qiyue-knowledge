# 七月的歌 · 弹唱知识库

无构建依赖的静态网站，适用于 GitHub Pages。

## 功能

- 曲谱：按歌名/歌手搜索，按吉他/尤克里里和 1–5 星筛选。
- 每首作品每种乐器展示一个默认编配；没有调性选择器。
- 从已校对 JSON 生成可点击的第一页网页曲谱；和弦、节奏打开底部教学面板，关闭后恢复原位。
- 保留原谱第一页查看；网站不包含完整 PDF。
- 教程分为基础系列和歌曲教学，当前全部标记“待更新”，不伪造教学内容。

## 本地预览

在本目录运行 `python3 -m http.server 8766`，打开 `http://127.0.0.1:8766`。

## GitHub Pages

把本目录的产品文件放在独立仓库根目录。Settings → Pages → Deploy from a branch → main / root。`.nojekyll` 保持原样静态发布。路由使用 `#/...`，兼容项目子路径及刷新。

## 内容维护

`catalog.js` 只包含获确认的第一页、指法和展示信息，勿放入完整曲谱、账户数据或密钥。

在原“七月的歌”工作区运行 `scripts/build_catalog.py`，可从知识库导出获确认作品的第一页。该脚本需要 Pillow 以及本地项目资料；线上网站不运行它。

教程录好后，添加课程数据、媒体和内容；现阶段没有账号、订单或支付。
